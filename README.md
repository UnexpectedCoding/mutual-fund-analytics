# 📊 Mutual Fund Analytics & Performance Evaluation System

> **An End-to-End Data Analytics & Business Intelligence Project for Evaluating Mutual Fund Performance, Investor Behaviour, and Market Trends using Python, SQLite, and Power BI.**

---

## 🚀 Project Overview

This project demonstrates the complete **Data Analytics lifecycle**, transforming raw mutual fund datasets into meaningful business insights through automated data processing, financial performance evaluation, advanced analytics, and interactive dashboards.

The solution combines **Data Engineering**, **Financial Analytics**, and **Business Intelligence** to help analyse fund performance, understand investor behaviour, evaluate portfolio risk, and support informed investment decisions.

---

## 🎯 Project Objectives

* Build an automated **ETL pipeline** for multiple financial datasets.
* Clean, validate, and integrate raw data into a structured database.
* Evaluate mutual fund performance using industry-standard financial metrics.
* Perform advanced risk and investor behaviour analysis.
* Design an interactive **Power BI Dashboard** for business decision-making.
* Demonstrate an end-to-end data analytics workflow from raw data to actionable insights.
